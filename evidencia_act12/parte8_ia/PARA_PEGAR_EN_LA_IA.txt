## Objetivo del Pull Request
Integrar la deformación topológica continua (**Morph Dona → Taza**) entre nuestros dos microservicios (`Calculadora de matrices` en el puerto `8000` y `Modelador3D_matrices` con interfaz *Glassmorphism* en el puerto `8001`).

   - **`operations.py` (`POST /operaciones/morph-3d` y `/calc/morph`):** Devuelve la nube de puntos interpolada y genera una tabla `resumen_markdown` con la caja envolvente (*bounding box*) lista para el agente de **n8n**.

4. **Suite de Pruebas (`test_e2e/`):**

+def vertice_dona(u: float, v: float, R: float = 10.0, r: float = 5.0) -> list[float]:
+    """Calcula un vértice del Toroide (Dona) en el dominio paramétrico (u, v)."""
+    x = (R + r * math.cos(v)) * math.cos(u)
+    y = (R + r * math.cos(v)) * math.sin(u)
+    z = r * math.sin(v)
+    return [x, y, z]

+def vertice_taza(u: float, v: float) -> list[float]:
+    """Calcula un vértice de una Taza con asa sobre el mismo dominio (u, v) en [0, 2*pi)."""
+    fraccion_asa = 0.25 * 2 * math.pi
+    if u < fraccion_asa:
+        # Asa lateral de la taza
+        s = u / fraccion_asa
+        ang = math.pi / 2 - math.pi * s
+        cx = 5.5 + 4.5 * math.cos(ang)
+        cy = 4.0 * math.sin(ang)
+        r_asa = 1.2
+        return [
+            cx + r_asa * math.cos(v) * math.cos(ang),
+            cy + r_asa * math.cos(v) * math.sin(ang),
+            r_asa * math.sin(v),
+        ]
+    else:
+        # Cuerpo cilíndrico hueco de la taza
+        s = (u - fraccion_asa) / (2 * math.pi - fraccion_asa)
+        r_cuerpo = 6.5
+        altura = 12.0
+        if s < 0.25:
+            # Base inferior
+            rad = (s / 0.25) * r_cuerpo
+            y = -altura / 2
+        elif s < 0.65:
+            # Pared exterior
+            rad = r_cuerpo
+            y = -altura / 2 + ((s - 0.25) / 0.40) * altura
+        else:
+            # Pared interior hueca

+            y = altura / 2 - ((s - 0.65) / 0.35) * (altura - 1.2)
+        return [
+            -2.0 + rad * math.cos(v),
